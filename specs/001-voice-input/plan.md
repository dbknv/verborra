# Implementation Plan: Voice Text Input

**Input**: Feature specification from `/specs/001-voice-input/spec.md`

## Summary

Native macOS Menu Bar application for voice text input. The user presses the global hotkey (Option+Space), an overlay panel (NSPanel) appears, recording automatically starts via AVAudioEngine. The audio (WAV, 16 kHz mono) is sent to the OpenAI Audio Transcriptions API, then the text goes through AI formatting via the Chat Completions API with a configurable system prompt. The result is displayed in a WYSIWYG Markdown editor (NSTextView + swift-markdown) and inserted into the target field via NSPasteboard + CGEvent Cmd+V.

**Project Type**: single (native desktop application)

**Constraints**: < 300 ms overlay response, < 50 MB RAM idle, recording file ≤ 25 MB, offline operation not required (depends on OpenAI API)
**Scale/Scope**: single-user desktop application, ~15 UI screens/states

## Key Architectural Decisions

All decisions are documented in [research.md](research.md):

1. **WYSIWYG Markdown editor**: NSTextView + swift-markdown (not WKWebView)
2. **Global hotkey**: KeyboardShortcuts (Carbon RegisterEventHotKey, without Accessibility permission)
3. **Audio capture**: AVAudioEngine → WAV PCM Int16 16 kHz mono in-memory
4. **OpenAI API**: URLSession async/await, non-streaming, multipart/form-data for Audio API
5. **Overlay window**: NSPanel (nonactivatingPanel, floating, canJoinAllSpaces)
6. **Text insertion**: NSPasteboard + CGEvent.postToPid() (Cmd+V)
7. **API key storage**: Security framework (kSecClassGenericPassword, kSecAttrAccessibleAfterFirstUnlock)
8. **Auto-launch**: SMAppService.mainApp
9. **Menu Bar**: SwiftUI MenuBarExtra + LSUIElement
10. **Prompts**: JSON in Application Support (Codable)
11. **OpenAI models**: global STT and LLM selectors, UserDefaults
12. **Language settings**: per-prompt voice language and text language (10 languages)

## System Permissions and Entitlements

### Entitlements (Verborra.entitlements)

| Entitlement | Value | Purpose |
|---|---|---|
| `com.apple.security.app-sandbox` | `true` | App Sandbox |
| `com.apple.security.device.audio-input` | `true` | Microphone access |
| `com.apple.security.network.client` | `true` | Outgoing connections (OpenAI API) |

### Runtime Permissions

| Permission | Why | When requested |
|---|---|---|
| Microphone | Audio capture via AVAudioEngine | On first recording or via button in settings |
| Accessibility | CGEvent.postToPid() for text insertion | Via button in settings (not on startup) |

### Distribution

- **Not Mac App Store** — CGEvent.postToPid() is blocked in sandbox without special entitlements
- **Notarized DMG** — direct download
- Accessibility permission is requested via `AXIsProcessTrustedWithOptions`
