## Заметки

- Дефолтное значение `answerQuestionsInFirstMessage` зафиксировано как **выключено** для всех промптов (см. «Предположения»). Это сознательное изменение поведения по сравнению с текущим main. Решение можно пересмотреть на `/speckit.clarify`, но это явное требование пользователя.
- Поведение редактирования сообщений (US4 / FR-006): требование задано на уровне «в payload уходит актуальный отображаемый текст». Конкретный механизм (готовый `onConfirmEdit` уже коммитит правку в модель сообщения) — деталь реализации, проверяется на этапе `/speckit.plan`.
- Правило усечения по лимиту модели (US4 / FR-007): «отбрасывать самые старые сообщения с начала, по одному, пока не помещается». Семантика однозначна, конкретный алгоритм с парами user/assistant — план реализации.
- Точная формулировка вспомогательной системной инструкции «не отвечать на вопросы» намеренно описана семантически, без литерального текста промпта — этот текст определяется в `/speckit.plan` и должен проходить ревью на качество (особенно для мультиязычных кейсов).
- Невыполненные пункты требуют обновления спецификации перед запуском `/speckit.clarify` или `/speckit.plan`.
